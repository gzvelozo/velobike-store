## Domain Knowledge

- Handoff flow: VELOBIKE mints a token via `/api/handoff`, then redirects shopper to `NEXT_PUBLIC_VELOMED_QUALIFY_URL?token=…` on the VeloMED side.
- HSA/FSA reimbursement requires a Letter of Medical Necessity (LMN) — generated by VeloMED's 3-agent pipeline (Clinical Evaluator → LMN Drafter → Quality Controller).
- Order persistence is idempotent via a Supabase unique constraint on `stripe_session_id`.
- Demo-mode fallback (`demo-<uuid>`) keeps the offline dev loop unblocked when VeloMED env vars are absent.
